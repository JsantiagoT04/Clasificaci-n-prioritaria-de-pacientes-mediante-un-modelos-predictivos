# Clasificaci-n-prioritaria-de-pacientes-mediante-un-modelos-predictivos
Implementación de un modelo de clasificación logística bayesiana enfocado en la priorización eficiente de pacientes. El proyecto abarcó desde la limpieza y preprocesamiento de un conjunto de datos de 1.500 registros y la interpretación estadística de coeficientes bajo incertidumbre, hasta la visualización de resultados
